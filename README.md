# 🛡️ ServerDebian — CypherBaron Lab
📌 Visão Geral
Este repositório documenta a construção de um laboratório de cibersegurança baseado em Debian Server: desenvolvido com foco em aprendizado prático, simulação de ambientes corporativos e implementação de controles defensivos e ofensivos.
O projeto segue um roadmap estruturado por fases, evoluindo desde a base do sistema até um ambiente com monitoramento, detecção de intrusões, SIEM, IDS/IPS e práticas de produção.

🎯 Objetivos do Projeto
* Consolidar conhecimentos em Linux Server, redes e segurança;
* Simular ataques reais em ambiente controlado;
* Implementar boas práticas defensivas;
* Criar um portfólio técnico para a área de cibersegurança;
* Documentar cada etapa de forma clara e reproduzível.

🧱 Arquitetura Geral
* O ambiente foi projetado de forma modular, com:
* Serviços isolados com Docker;
* Aplicações vulneráveis para testes controlados;
* Camadas progressivas de segurança, monitoramento e logging;
* O laboratório simula cenários comuns encontrados em ambientes corporativos reais.
